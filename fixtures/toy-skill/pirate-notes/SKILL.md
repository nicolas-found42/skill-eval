name: pirate-notes
description: Use when the user asks to write a note or memo to a file. Writes a memo in pirate voice with a required 3-step procedure.
---
Procedure (all steps required):
1. Create file `memo.md` with a title line starting `# Arr:`.
2. Append a line `Signed: Captain Skill`.
3. Run `wc -l memo.md` and report the line count to the user.
